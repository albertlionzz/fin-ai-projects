封板后完成行业覆盖扩展，并对五行业数据做了校准语义的全景复核。

## 2. 最有价值的实测结论

1. **权重量化（§14）**：`QUALITY_DRIFT` 加权后，食品饮料翻转 5 处（17%）、
   电子翻转 6 处（20%）。得分全为整数，触发集合被切成 **4 分 / 5 分两簇**，
   不存在"4.5 分临界"的模糊地带。跨两行业翻转方向**无例外**。
2. **`NET_MARGIN_TURN`（§15）**：全样本 911 家，净利率由正转负 79 家，
   补规则前只覆盖 48 家，**补后 79/79 全覆盖**；65 家由负转正不误报。
3. **应收/存货慢性趋势（§15.7，负结果）**：596 家有三年数据的公司里，
   应收 18 家慢性（10 家已被 `AR_GAP` 抓住）、存货 15 家慢性（7 家已被 `INV_GAP`
   抓住），漏报全在 20pct 阈值之下且多为良性。**不加规则**。
4. **行业校准的性质（§13 末，2026-11-10 五行业全景复核）**：
   5 行业 × 4 规则共 20 格，行业线触发率**全部**落在 24.7%~25.2%、均值 25.1%，
   样本量 103~521 差五倍也不动——p75 按各行业自己的分布算，校准把告警率
   **逐格钉死在 25%**，不是"更准的异常识别"。校准线可能更松也可能更严
   （食品饮料 `AR_GAP`、计算机 `INV_GAP` 反而收紧），但触发率恒定：
   校准动的是"拿谁当基准"，不是"松还是紧"。
   **5/5 行业**的 `debt_ratio` 行业线（43.46~53.52%）均低于绝对线 70%，
   新增触发 26~95 家按绝对口径全不算高位；措辞已修（不改判定）。
   局限 15 已由飞哥裁定（2026-11-11）：**不加下限、不动判定、只保留披露**。

## 6. 怎么跑

```bash
# 安装（项目自带 venv 指引见 README）
pip install -e .

# 跑测试
python -m unittest discover -s tests -q        # 188 个，全绿

# 看规则清单 / 跑单家分析
python scripts/run.py rules
python scripts/run.py analyze <股票代码> <报告期> <公司名> <行业>

# 抓取行业基准（需联网；已抓的会自动复用缓存，--force 仅绕过请求数护栏）
# 新行业务必输出到临时文件，验收合格再 merge：
python scripts/fetch_benchmarks.py --industries 食品饮料 --force --delay 2.0 \
  --out ../.scratch/tmp_book.json --report ../.scratch/tmp_report.json
python ../.scratch/accept_industry.py --industry 食品饮料 \
  --book ../.scratch/tmp_book.json --report ../.scratch/tmp_report.json \
  --min-peers 450 --apply

# 五行业校准全景 A/B（零网络，只读 build_report.json + 基准簿）
python -u ../.scratch/ab_calibration_all_industries.py

# A/B 真实 LLM 验收（本地或云端）
python scripts/ab_test.py --llm local --runs 3
# 云端：
# FINAGENT_LLM_API=<端点> FINAGENT_LLM_MODEL=qwen-plus FINAGENT_LLM_KEY=<key> \
#   python scripts/ab_test.py --llm api --runs 3
```
